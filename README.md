# Pawsitive Pet Academy - Mobile App

XHAW5112 Work Integrated Learning 1, Task 2 Phase 2 (React Native with Expo).

## Screens
Home, About Us (history, vision, mission, goals), Courses (six-month and six-week), Individual Course, Calculate Fees (discount + 15% VAT), Contact Us, and a slide-out menu.

## Run it
1. Install Node.js (LTS) from nodejs.org
2. In this folder run: `npm install`
3. Run: `npx expo start`
4. Scan the QR code with the Expo Go app on your phone (or press `w` to open it in the browser)

## Fee rules (from the brief)
- 1 course: no discount, 2 courses: 5%, 3 courses: 10%, more than 3: 15%
- 15% VAT is added after the discount
- The total is a quoted fee, not a formal invoice
